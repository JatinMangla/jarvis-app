# Jarvis app (releases only)

This repository holds **only** the installable Android app of Jarvis, a private voice
assistant: the APK, its SHA-256 checksum and `latest.json` (what the app reads to
update itself). No source code and no secrets are here; a GitHub Action in a private
repository publishes each version. Only the newest version is kept.

**Latest: 0.2.0** -> [download jarvis-0.2.0.apk](https://raw.githubusercontent.com/JatinMangla/jarvis-app/main/apk/jarvis-0.2.0.apk)

First install on the phone: tap the download link above. Chrome asks to allow
"install unknown apps": Settings -> Allow from this source -> back -> Install.
After that, the app updates itself.
